# Specification

## Summary
**Goal:** Create a simple 2-page printing service website for WITH PRINT that displays pricing information and accepts payment confirmations via PhonePe QR code.

**Planned changes:**
- Build home page displaying business name, pricing table (B&W ₹1/page, Color ₹10/page), delivery information, and contact details with call timings
- Add "Proceed to Payment" button that navigates to payment page
- Create payment page with PhonePe QR code, UPI details (9392673014@axl, Kairamkonda Upendra Devi), and step-by-step payment instructions
- Implement payment confirmation form with fields for name, email, phone, UTR/transaction ID, and screenshot upload
- Add blue Submit button that stores confirmation data in backend
- Display success message after submission confirming delivery timeline
- Apply clean, professional design with warm colors suitable for college students

**User-visible outcome:** College students can view printing prices, proceed to payment, scan the PhonePe QR code, complete payment, and submit confirmation details with a screenshot to receive printing services with next-day delivery.
